Bearer Token Authentication

Protected endpoints require an Authorization: Bearer <token> header. Obtain a token from POST /auth/admin/login (admin) or POST /school/auth/login (school portal).

Authentication

User registration, OTP, login, PIN management

@if (isExpanded('auth-otp-reg')) {
lock_open Authentication: None required

Sends a 6-digit OTP to the provided phone number as the first step of user registration.

Request Body

{
  "phoneNumber": "08012345678"
}

Responses

200 OK 
{
  "success": true,
  "message": "OTP sent",
  "data": {
    "message": "OTP sent to your phone",
    "phoneNumber": "08012345678",
    "expiresAt": "2026-04-28T10:10:00Z",
    "reference": "otp-ref-abc123"
  },
  "timestamp": "2026-04-28T10:00:00Z"
}
}
@if (isExpanded('auth-register')) {
lock_open Authentication: None required

Completes user registration. Requires a valid OTP obtained from POST /auth/otp/registration.

Request Body

{
  "phoneNumber": "08012345678",
  "firstName": "Chidi",
  "lastName": "Okafor",
  "otpCode": "123456"
}
}
@if (isExpanded('auth-otp-pin')) {

Triggers OTP for first-time PIN setup after registration.

}
@if (isExpanded('auth-pin-set')) {

Sets a 4-digit transaction PIN. Requires OTP verification.

Request Body

{
  "phoneNumber": "08012345678",
  "otpCode": "123456",
  "pin": "1234"
}
}
@if (isExpanded('auth-pin-change')) {
lock Authentication: Bearer Token

Changes an existing transaction PIN. All three fields are required and must be 4 digits.

Request Body

{
  "oldPin": "1234",
  "newPin": "5678",
  "confirmNewPin": "5678"
}
}
