Getting Started

Welcome to the Solexpay API. Our API is organized around REST. Our API has predictable resource-oriented URLs, accepts form-encoded request bodies, returns JSON-encoded responses, and uses standard HTTP response codes, authentication, and verbs.

lock

Authentication

The Solexpay API uses Bearer tokens to authenticate requests. You can generate a token by logging in via the Auth endpoints. Your API tokens carry significant privileges, so be sure to keep them secure!

Authorization: Bearer <TOKEN>

Error Codes

How our API communicates errors and validation failures.

Status Name Description
400 Bad Request Validation failed or malformed JSON body.
401 Unauthorized Invalid or missing Authorization header.
403 Forbidden Auth is valid but you lack required permissions (e.g., non-admin calling admin route).
404 Not Found The requested resource or endpoint does not exist.
422 Unprocessable Business logic violation (e.g., insufficient funds).
